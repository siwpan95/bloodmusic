你是否想过用代码创作音乐？是否需要为应用程序生成自定义提示音、背景音乐？**Synthesizer** 库让这一切变得简单——它是Python中一款轻量级音频合成工具，能通过代码生成正弦波、方波等基础波形，组合出旋律、和弦，甚至简单的音乐片段。本文将带你从基础波形生成到完整旋律创作，解锁用代码“作曲”的乐趣。
一、什么是Synthesizer？
Synthesizer（音频合成器）是一个专注于实时音频生成的Python库，它的核心能力是通过数学公式生成不同波形的音频信号，并将这些信号组合成可播放或保存的音频文件。与专业DAW（数字音频工作站）相比，它的优势在于：
-
代码驱动：无需界面操作，用函数调用定义音高、时长、音色，适合自动化生成音频；
-
轻量灵活：不依赖庞大的音色库，通过参数调整即可生成丰富的音色；
-
实时反馈：支持直接播放生成的音频，便于快速调试；
-
易于集成：可与游戏、应用程序结合，动态生成提示音、背景音乐。
如果你是开发者、音乐爱好者，或需要为项目生成自定义音频，Synthesizer会是一个有趣且实用的工具。
二、环境准备：安装与基础验证
安装Synthesizer
Synthesizer依赖于numpy
（信号处理）和sounddevice
（音频播放），安装命令：
pip install synthesizer sounddevice numpy
验证安装：生成第一个声波
运行以下代码，生成一个440Hz的正弦波（标准A音，小提琴的空弦音）并播放：
from synthesizer import Player, Synthesizer, Waveform
# 初始化播放器（指定采样率，44100是CD音质标准）
player = Player(sample_rate=44100)
player.open_stream() # 打开音频流
# 初始化合成器（指定波形、振幅、采样率）
synthesizer = Synthesizer(
waveform=Waveform.sine, # 正弦波（音色柔和）
amplitude=0.5, # 音量（0-1之间，避免过大失真）
sample_rate=44100
)
# 生成440Hz的音频，时长1秒（单位：秒）
audio = synthesizer.generate_constant_wave(frequency=440, duration=1.0)
# 播放音频
player.play_wave(audio)
运行后，你会听到一个持续1秒的“嗡”声——这是最基础的音频合成效果。
三、核心概念：音频合成的基本要素
在深入使用前，需要了解几个音频合成的核心概念，这是用代码“创作”的基础：
-
波形（Waveform）：决定音色的关键。不同波形（正弦波、方波、锯齿波）的谐波组成不同，听起来音色差异很大（如正弦波柔和，方波尖锐）。
-
频率（Frequency）：决定音高，单位Hz。例如：A4（标准音）是440Hz，C4（中央C）是261.63Hz。
-
振幅（Amplitude）：决定音量，范围0-1，过大会导致音频失真。
-
时长（Duration）：音符的持续时间，单位秒。
-
采样率（Sample Rate）：每秒采集的音频样本数，常见44100Hz（CD音质）、48000Hz（专业设备），越高音质越好，但文件越大。
四、基础用法：波形、音高与旋律
1. 不同波形的音色差异
Synthesizer支持多种基础波形，通过对比可以直观感受音色差异：
from synthesizer import Player, Synthesizer, Waveform
import time
player = Player(sample_rate=44100)
player.open_stream()
# 定义要测试的波形和频率（A4=440Hz）
waveforms = [
(Waveform.sine, "正弦波（柔和）"),
(Waveform.square, "方波（尖锐）"),
(Waveform.sawtooth, "锯齿波（沙哑）"),
(Waveform.triangle, "三角波（明亮）")
]
for waveform, name in waveforms:
synth = Synthesizer(waveform=waveform, amplitude=0.5, sample_rate=44100)
print(f"播放：{name}")
audio = synth.generate_constant_wave(440, duration=1.5) # 持续1.5秒
player.play_wave(audio)
time.sleep(0.5) # 间隔0.5秒
播放后能明显听出：正弦波最柔和，方波带有明显的“毛刺感”，锯齿波类似弦乐摩擦声，三角波介于正弦波和方波之间。
2. 生成指定音高的音符
音乐中的音高对应特定频率，我们可以通过频率生成Do、Re、Mi等音符。以下是C大调基本音符的频率表（基于十二平均律）：
| 音符 | 频率（Hz） | 音符 | 频率（Hz） |
| C4（Do） | 261.63 | G4（Sol） | 392.00 |
| D4（Re） | 293.66 | A4（La） | 440.00 |
| E4（Mi） | 329.63 | B4（Si） | 493.88 |
| F4（Fa） | 349.23 | C5（高Do） | 523.25 |
利用这些频率生成一段简单旋律：
from synthesizer import Player, Synthesizer, Waveform
# 定义C大调音符频率（C4到C5）
notes = {
"C4": 261.63,
"D4": 293.66,
"E4": 329.63,
"F4": 349.23,
"G4": 392.00,
"A4": 440.00,
"B4": 493.88,
"C5": 523.25
}
# 初始化播放器和合成器（用正弦波，音色柔和）
player = Player(44100)
player.open_stream()
synth = Synthesizer(Waveform.sine, 0.5, 44100)
# 《小星星》前四句旋律（音符 + 时长）
melody = [
("C4", 0.5), ("C4", 0.5), ("G4", 0.5), ("G4", 0.5),
("A4", 0.5), ("A4", 0.5), ("G4", 1.0),
("F4", 0.5), ("F4", 0.5), ("E4", 0.5), ("E4", 0.5),
("D4", 0.5), ("D4", 0.5), ("C4", 1.0)
]
# 播放旋律
for note, duration in melody:
freq = notes[note]
audio = synth.generate_constant_wave(freq, duration)
player.play_wave(audio)
print("旋律播放完成！")
运行后，你会听到熟悉的《小星星》片段——这是用纯代码生成的音乐！
3. 调整音色：振幅包络与颤音
单纯的持续波形听起来很生硬，通过调整**振幅包络**（Attack-Decay-Sustain-Release，ADSR）可以让音符更自然，类似乐器的“起音-衰减-持续-释音”过程：
from synthesizer import Player, Synthesizer, Waveform
from synthesizer.envelope import Envelope # 导入包络类
# 定义ADSR包络（参数：起音时间、衰减时间、持续音量、释音时间）
envelope = Envelope(
attack=0.1, # 0.1秒内音量从0升到最大（起音）
decay=0.2, # 0.2秒内音量从最大衰减到持续音量
sustain=0.7, # 持续阶段的音量（最大音量的70%）
release=0.5 # 0.5秒内音量从持续音量降到0（释音）
)
# 初始化合成器时应用包络
player = Player(44100)
player.open_stream()
synth = Synthesizer(
waveform=Waveform.sine,
amplitude=0.5,
sample_rate=44100,
envelope=envelope # 应用ADSR包络
)
# 播放一个带包络的音符（对比之前的生硬波形）
audio = synth.generate_constant_wave(440, duration=2.0) # 总时长2秒
player.play_wave(audio)
加入包络后，音符会有自然的“渐强-减弱-保持-渐弱”过程，更接近真实乐器的音色。
此外，还可以添加**颤音**（vibrato）——通过频率的快速波动增加表现力：
# 生成带颤音的音频（频率440Hz，颤音频率5Hz，颤音幅度2Hz）
audio = synth.generate_constant_wave(
frequency=440,
duration=2.0,
vibrato_frequency=5.0, # 颤音频率（每秒波动5次）
vibrato_amplitude=2.0 # 颤音幅度（频率上下波动2Hz）
)
player.play_wave(audio)
颤音让音符听起来更生动，类似歌手或弦乐演奏时的颤音效果。
五、实战：生成和弦与背景音乐
1. 合成和弦（多音符同时播放）
和弦由多个不同频率的音符同时发声组成，通过合并多个波形实现：
import numpy as np
from synthesizer import Player, Synthesizer, Waveform
player = Player(44100)
player.open_stream()
synth = Synthesizer(Waveform.sine, 0.3, 44100) # 降低振幅避免叠加失真
# C大三和弦（C4、E4、G4同时发声）
def generate_chord(frequencies, duration):
# 生成每个音符的波形
waves = [synth.generate_constant_wave(freq, duration) for freq in frequencies]
# 合并波形（叠加后归一化，避免音量过大）
combined = np.sum(waves, axis=0)
return combined / np.max(np.abs(combined)) # 归一化到[-1, 1]
# C大三和弦（C4=261.63, E4=329.63, G4=392.00）
c_major = [261.63, 329.63, 392.00]
chord_audio = generate_chord(c_major, duration=2.0)
player.play_wave(chord_audio)
# G大三和弦（G4=392.00, B4=493.88, D5=587.33）
g_major = [392.00, 493.88, 587.33]
chord_audio = generate_chord(g_major, duration=2.0)
player.play_wave(chord_audio)
播放后能听到和谐的和弦音效，这是背景音乐的基础。
2. 生成循环背景音乐
结合旋律和和弦，生成一段可循环的背景音乐（如游戏场景音乐）：
import numpy as np
from synthesizer import Player, Synthesizer, Waveform
from synthesizer.envelope import Envelope
# 初始化工具
player = Player(44100)
player.open_stream()
envelope = Envelope(attack=0.05, decay=0.1, sustain=0.6, release=0.3)
synth = Synthesizer(Waveform.sine, 0.3, 44100, envelope=envelope)
# 定义音符频率
notes = {
"C4": 261.63, "D4": 293.66, "E4": 329.63, "G4": 392.00,
"C5": 523.25, "E5": 659.25, "G5": 783.99
}
# 生成和弦的函数（复用之前的逻辑）
def generate_chord(frequencies, duration):
waves = [synth.generate_constant_wave(freq, duration) for freq in frequencies]
combined = np.sum(waves, axis=0)
return combined / np.max(np.abs(combined))
# 背景音乐结构：4小节和弦 + 简单旋律
background = []
# 第1-2小节：C大三和弦（持续2秒）
background.append(generate_chord([notes["C4"], notes["E4"], notes["G4"]], 2.0))
# 第3-4小节：G大三和弦（持续2秒）
background.append(generate_chord([notes["G4"], notes["B4"], notes["D5"]], 2.0))
# 合并和弦为循环片段
loop = np.concatenate(background)
# 播放循环（重复3次）
for _ in range(3):
player.play_wave(loop)
print("背景音乐播放完成！")
这段代码生成的循环音乐可作为游戏场景、视频背景的简易配乐，通过调整波形和和弦还能改变风格（如用方波制作电子乐，用锯齿波制作摇滚风）。
六、保存音频：生成WAV文件
除了实时播放，Synthesizer还能将生成的音频保存为WAV文件，方便后续使用：
from synthesizer import Synthesizer, Waveform
import numpy as np
import wave # Python内置WAV文件处理库
# 生成一段音频（如《小星星》片段）
synth = Synthesizer(Waveform.sine, 0.5, 44100)
notes = {"C4": 261.63, "G4": 392.00, "A4": 440.00, "F4": 349.23, "D4": 293.66}
melody = [("C4", 0.5), ("C4", 0.5), ("G4", 0.5), ("G4", 0.5)]
audio_segments = [synth.generate_constant_wave(notes[note], dur) for note, dur in melody]
audio = np.concatenate(audio_segments) # 合并片段
# 保存为WAV文件
def save_wav(file_path, audio, sample_rate=44100):
# 音频数据需转换为16位整数（WAV文件常用格式）
audio_int16 = np.int16(audio * 32767) # 32767是16位整数的最大值
with wave.open(file_path, "wb") as wf:
wf.setnchannels(1) # 单声道
wf.setsampwidth(2) # 16位（2字节）
wf.setframerate(sample_rate)
wf.writeframes(audio_int16.tobytes())
save_wav("twinkle_twinkle.wav", audio)
print("音频已保存为twinkle_twinkle.wav")
生成的WAV文件可用于手机铃声、应用提示音，或导入到音频编辑软件进一步处理。
七、进阶方向与注意事项
1. 进阶玩法
-
多声道合成：通过生成左右声道不同的音频，实现立体声效果；
-
音色调制：结合滤波（Filter）、失真（Distortion）等效果器，生成更复杂的音色；
-
节奏控制：通过精确控制音符时长和间隔，实现鼓点、节拍；
-
MIDI文件交互：解析MIDI文件（音乐数字接口），用Synthesizer播放标准乐谱。
2. 注意事项
-
音量控制：多音符叠加时需归一化（如
combined / np.max(np.abs(combined))
），否则会因音量过大导致失真； -
性能限制：生成过长或过复杂的音频可能占用较多内存，建议分片段处理；
-
依赖问题：
sounddevice
播放音频可能需要额外驱动（如Windows的ASIO、macOS的Core Audio），若播放失败可尝试更新驱动或保存为WAV文件播放。
