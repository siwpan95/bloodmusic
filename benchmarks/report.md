# RealtimeMusicEngine 性能基准

- 环境: Python 3.14.6 / numpy 2.4.6
- 测量: 200 帧/配置（预热 10 帧）
- 60fps 单帧预算: **16.6 ms**

| 配置 | 均值 | 中位数 | P95 | 最坏 | 60fps 可行 |
|------|------|--------|-----|------|-----------|
| 2 层 / buffer 128 | 1.39 ms | 1.36 ms | 2.02 ms | 2.59 ms | **是** |
| 4 层 / buffer 128 | 1.49 ms | 1.55 ms | 2.01 ms | 2.63 ms | **是** |
| 6 层 / buffer 128 | 1.13 ms | 0.93 ms | 1.67 ms | 1.92 ms | **是** |
| 8 层 / buffer 128 | 1.05 ms | 0.86 ms | 1.61 ms | 1.88 ms | **是** |
| 2 层 / buffer 256 | 1.90 ms | 2.06 ms | 2.79 ms | 3.01 ms | **是** |
| 4 层 / buffer 256 | 1.96 ms | 1.79 ms | 3.01 ms | 3.75 ms | **是** |
| 6 层 / buffer 256 | 2.20 ms | 2.32 ms | 2.94 ms | 3.08 ms | **是** |
| 8 层 / buffer 256 | 2.12 ms | 2.33 ms | 2.99 ms | 3.28 ms | **是** |
| 2 层 / buffer 512 | 3.55 ms | 3.94 ms | 4.72 ms | 5.87 ms | **是** |
| 4 层 / buffer 512 | 3.26 ms | 3.55 ms | 4.73 ms | 5.95 ms | **是** |
| 6 层 / buffer 512 | 3.21 ms | 3.41 ms | 4.68 ms | 5.81 ms | **是** |
| 8 层 / buffer 512 | 3.46 ms | 3.89 ms | 5.05 ms | 5.45 ms | **是** |

## 结论

- 实时可行（P95 ≤ 16.6 ms）的配置共 12 个，最大可行层密度: **8 层 / buffer 128**（P95 1.61 ms）
- 建议: 游戏实时使用时优先选择可行配置中 buffer 较小者，兼顾延迟与算力余量；超出上限的密度应改为预渲染/离线模式

> 注: 单次 process_frame 不含音频设备 I/O 延迟；实际游戏集成需额外预留 sounddevice/游戏引擎缓冲时间。
